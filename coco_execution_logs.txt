  Snowflake Data & SQL

  • Document intelligence -- extract, parse, OCR, classify PDFs/images/files on stages

  • Build Cortex Agents and semantic views for conversational analytics

  Data Engineering

  • Dynamic tables, tasks, Snowpipe Streaming -- create, monitor, troubleshoot pipelines
  • dbt -- explore dbt projects (fdbt), deploy dbt to Snowflake, verify builds
  • Openflow -- connector deployment and diagnostics
  • Spark migration -- convert PySpark to Snowpark

  Application Development

  • Streamlit apps -- build, deploy, and debug Streamlit-in-Snowflake

  • Native Apps -- provider and consumer workflows
  • Snowpark Python -- write pipelines, UDFs, stored procedures

  Governance & Security

  • Data governance -- classification, masking, row-access policies, tagging
  • Access troubleshooting -- debug permission errors, analyze role grants
  • Security investigations -- login anomalies, data exfiltration, privilege escalation
  • Network policies, authentication policies, SSO setup, Trust Center

  Cost & Operations

  • Cost intelligence -- credit usage by warehouse/user/service, budgets, anomaly detection
  • Billing -- org-level dollar spend, invoices, contracts
  • Warehouse tuning -- sizing, adaptive warehouses, performance analysis
